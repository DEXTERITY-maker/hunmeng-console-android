## Приоритет источников

1. Поведение и точные подписи — NEXT-UPDATE.md.
2. Бренд и launcher — существующий app-icon-source.png и PrepareLauncherIcon.java.
3. PNG — композиция, визуальная иерархия и темы. Мелкие перерисовки робота и возможные неточности букв не заменяют исходники.
4. SVG — форма и значение элементов. В Compose использовать vector/drawable или штатные Material-иконки; в вебе — SVG. Не вставлять весь PNG вместо интерфейса.

## Оформление — предложение для согласования

- Сохранить текущую структуру нативного Kotlin / Compose и веб-приложения.
- Светлый фон #F6F8FC, карточка #FFFFFF, текст #152238; тёмный фон #0E1923, карточка #192631, текст #F2F6FA.
- Акцент #007AFF; дополнительный текст в светлой теме #52617A, в тёмной #B5C5D8. При реализации проверить контраст всех состояний.
- Скругление карточек 16 dp, диалогов 20 dp; основные отступы 16 dp. Нажимаемые элементы не меньше 48 dp.
- Основной текст около 16 sp, заголовки 24 sp. Масштаб текста — системный. Короткие подписи; username при недостатке места переносится или сокращается, полный доступен в карточке.
- Цвет дополняется подписью/иконкой состояния. Кнопки загрузки защищены от повторных нажатий. Диалог имеет доступные labels и фокус.
- Внешние поля учитывают status bar, navigation bar и клавиатуру. Увеличенный шрифт не скрывает действия; длинные списки прокручиваются.

## Иконки интерфейса

Лист icons.svg — исходник с векторными формами 24×24, штрих 1.8, круглыми концами. Самолёт означает Telegram, мегафон — канал, несколько людей — группу, поиск — фильтрацию, круговые стрелки — обновление списка, карточка — шаблон, закладка — избранное, солнце/луна — тему. Это ориентиры; не новые launcher-иконки и не официальные файлы бренда Telegram.

Изображения созданы встроенной генерацией изображений как концепты. Промпт: «Hunmeng Console v0.0.5beta; два Android-экрана рядом; светлая/тёмная тема; существующая иконка; читаемые русские подписи; карточки ботов, затем отдельно каналы и группы; только примеры данных; без токенов и личных данных». Для экрана входа отдельная правка заменила текст карточки на «После входа откроется раздел „Мои боты“». Все точные требования к реализации находятся в плане.
