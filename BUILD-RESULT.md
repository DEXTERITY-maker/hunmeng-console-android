## Границы проверки

- Реальный Telegram API при разработке не вызывался. Сообщения не отправлялись, webhook и настройки живого бота не менялись.
- Существующие файлы с токенами не читались; токены не включены в исходники, отчёты или CI.
- В приложении токен хранится только в памяти, ввод скрыт, autofill отключён, при отключении ссылка очищается. Резервное копирование и перенос данных между Android-устройствами отключены явными правилами.
- Polling работает на переднем плане. Постоянная фоновая служба и источник обновлений APK не настроены.
- Установка и визуальная работа на телефоне ещё не подтверждены: системный установщик требует действия владельца. Подключение реального бота проверяется после установки в приложении.
- Локальная Android-сборка в Termux ARM64 не выполнялась: официальный native toolchain x64 здесь не подходит; проверенная сборка выполнена на Ubuntu в CI.
