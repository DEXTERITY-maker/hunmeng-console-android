# Постоянная подпись будущих выпусков

На телефоне создан отдельный постоянный RSA-3072 ключ для release APK. Ключ, пароль и приватная резервная копия находятся только в приватном Termux-хранилище; в GitHub и общую память телефона не копировались. CI собирает debug и unsigned release APK. Постоянный ключ использован локально для [промежуточного кандидата](v0.0.5-release-candidate.md); финальный выпуск ещё не опубликован.

Открытый SHA-256 сертификата:
`d052c3aa276facde5f2bab22713ae76e31fc1b3a1262bc7e6b284df5522a554a`

Публичный сертификат отличается от всех прежних debug-сборок. Это обеспечивает постоянство будущих подписей, но не делает будущий APK совместимым с уже установленным старым сертификатом. На телефоне ничего не удалялось и не переустанавливалось. Перед финальным выпуском использовать [процесс подготовки](../tools/RELEASE-PREPARATION.md), затем отдельно проверить настоящий вход и совместимое обновление.
