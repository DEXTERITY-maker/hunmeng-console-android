## Проверка доступа к телефону

Обычный `adb devices -l` сначала получил linker error: Codex запускается с `LD_LIBRARY_PATH`, указывающим на собственную C++-библиотеку, которая не совместима с установленным android-tools. Изолированная команда `env -u LD_LIBRARY_PATH -u LD_PRELOAD adb devices -l` успешно выполнилась и вернула пустой список. Пакеты, глобальная среда и библиотеки не изменялись. Авторизованное ADB-устройство не подключено; установка, системный Login callback, клавиатура и физический поворот телефона не проверены.

## Оставшиеся шаги

1. Выбрать представляющего приложение бота; в мини-приложении BotFather → **Login Widget** получить публичный Client ID и настроить Allowed URLs. Client Secret вводится только через защищённые runtime-настройки backend. [Официальная инструкция Telegram](https://core.telegram.org/bots/telegram-login).
2. Сборка с настоящим Client ID, проверка полного Login/TDLib пути на устройстве и API ID/hash через приложение. Коды входа и секреты в переписку не передавать.
3. Согласованные метаданные версии, подписанный финальный APK, фактические release notes/JSON и GitHub Release.
4. Проверка установки и реального совместимого обновления; существующее приложение не удалять автоматически.
