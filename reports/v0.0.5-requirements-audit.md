## Повторно проверенные официальные источники

- [Telegram Login/OIDC](https://core.telegram.org/bots/telegram-login): зарегистрированные URL, Authorization Code/PKCE и серверная проверка. Login-профиль не является сессией TDLib.
- [TDLib getOwnedBots](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_owned_bots.html) и [bots.getAdminedBots](https://core.telegram.org/method/bots.getAdminedBots): официальный источник ботов текущего пользователя, требуется пользовательская авторизация.

Текущие внешние проверки: backend config HTTP 200 / configured=true; actual Android assetlinks HTTP 200 / совпали ожидаемые package, постоянный сертификат и relation. Только эти факты установлены живыми запросами; они не подтверждают установку или код авторизации.
