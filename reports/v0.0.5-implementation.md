# v0.0.5beta — промежуточная реализация

Обновлено 4 октября 2026 года. Ветка `codex/v005-account-session`, draft PR #1. Выпуск Android v0.0.5beta пока не готов: APK сохраняет 0.0.4-beta / код 2, настоящий вход требует настройки владельца.

## Реализовано в коде

- AES-256-GCM, Android Keystore, AtomicFile в `noBackupFilesDir`, резервное копирование отключено. Отдельные vault для аккаунта, незавершённого входа и явно сохранённых инструментов. Bot API-токены остаются в памяти.
- Профиль подтверждается сервером Telegram Login и открывает «Мои боты» сразу. TDLib подключается после отдельного согласия; её `getMe` должен совпасть со стабильным Telegram ID профиля.
- Незавершённая попытка входа переживает пересоздание процесса в зашифрованном виде. Callback проверяет точные scheme/host/path, state, дубликаты параметров, срок и однократность. Обмен code, PKCE verifier, JWT и Client Secret остаются на сервере.
- Документированный OIDC-переход через браузерную вкладку. Native SDK изучен: его штатный обмен на устройстве не использован. Cross-app путь SDK ещё не проверен и не заявлен работающим. Настройка Android app link и реальный возврат требуют проверки после регистрации приложения в BotFather.
- Один нативный TDLib receiver на процесс; эксклюзивное владение приватным каталогом базы, закрытие при уничтожении ViewModel. Нативные логи отключены; message/file/chat info databases отключены. Авторизация клиента — отдельное подтверждение в Telegram; пароль двухэтапной проверки при необходимости вводится в защищённом экране и не сохраняется.
- Официальный источник `getOwnedBots`, проверка принадлежности выбранного бота текущему аккаунту. «Доступные каналы и группы» охватывают чаты пользователя; роль и права принадлежат боту. Данные могут быть пустыми, недоступными, неполными или устаревшими — состояния различаются.
- Навигация «Мои боты / Консоль / Профиль» и внутренние вкладки «Бот / Сообщение / События» используют одну консоль. Выбор бота не подключает токен, не запускает polling и не отправляет сообщения.
- Токен консоли проверяется на совпадение с выбранным ботом. Перед предпросмотром и подтверждённой отправкой в канал/группу заново проверяются получатель и права; неизвестное разрешение блокирует отправку.
- Темы, счётчики текущего подключения, редактируемые шаблоны и избранные получатели. Без входа инструменты остаются в памяти; после подтверждения аккаунта сохраняются зашифрованными только для его ID. Права получателя из сохранённых данных не восстанавливаются как действующие.
- Выход немедленно инвалидирует запросы и очищает консоль; закрывает TDLib, удаляет её каталог, vault и ключи. Локальная ошибка блокирует новый вход; недоказанный удалённый отзыв сообщается отдельно. Личные Telegram-сообщения не удаляются.
- Обновления читают Android JSON из репозитория. Проверяются platform/package, versionCode, APK URL, размер, SHA-256, versionName и сертификат. Несовместимая подпись не запускает установку. Скачивание и системный установщик требуют действий пользователя; автоматического удаления приложения нет. «Позже» действует 24 часа для этого выпуска; «Что нового» показывается один раз для подтверждённого установленного выпуска.

## Что ещё требуется для выпуска

1. Подтвердить в BotFather регистрацию Android package/постоянного сертификата и рабочего App Link для `@hunmeng_official_bot`. Client ID/Secret уже настроены на сервере. [Данные для настройки](../server/telegram-login/OWNER-SETUP.md).
2. Проверить вход/отмену/возврат/восстановление на устройстве в подготовленном кандидате с настоящим Client ID; настоящий TDLib getMe/getOwnedBots и права в доступных чатах. API ID/hash владелец вводит в приложении, не в переписке.
3. Финальный APK с согласованными метаданными v0.0.5beta, реальный release JSON с его хешем/сертификатом, публикация релиза. Постоянный ключ и локальная подпись кандидата проверены; несовместимость со старой debug-подписью остаётся.
4. Проверка установки, клавиатуры, крупного шрифта, поворота и реального callback на телефоне. Реальные сообщения и настройки ботов во время разработки не изменялись.
