# Проверка нового интерфейса на телефоне

10 октября 2026 года, Москва. Этот документ перечисляет незавершённые проверки владельца. Результаты CI и подпись кандидата записываются отдельно в [отчёте кандидата](v0.0.5-release-candidate.md). Ни один пункт ниже не объявляется пройденным заранее.

## Установка

Открыть актуальный файл `Hunmeng-Console-UI-candidate-37998764751.apk` из Download и подтвердить обычный установщик Android. Package сохраняется: `chat.hunmeng.console`; версия кандидата — `0.0.4-beta`, код 2. Это проверка интерфейса следующего обновления, а не опубликованная v0.0.5beta.

Постоянный сертификат кандидата отличается от подписей прежних публичных APK. Если установлен другой сертификат, Android отклонит обновление. Сообщить точный текст отказа; не удалять приложение автоматически и не считать открытие установщика успешной установкой. Совместимость со сборкой с тем же постоянным сертификатом должна быть проверена отдельно.

## Сценарии

1. **Версия и оформление.** После установки открыть приложение, проверить исходную синюю иконку владельца и `v0.0.4beta`. Переключить RU/EN, светлую, тёмную и системную тему. При крупном системном шрифте заголовки переносятся, элементы доступны прокруткой; текст не уменьшать принудительно.
2. **Вход.** «Мои боты» → «Войти через Telegram» открывает официальную страницу Telegram. Отменить первую попытку и проверить возврат; затем подтвердить вход. После подтверждённого профиля открывается «Мои боты». Проверить возврат из Telegram после пересоздания приложения и однократную обработку callback. Коды и пароль вводить только на соответствующем защищённом экране, не присылать в чат и не помещать в отчёт.
3. **Отдельное подключение клиента.** Прочитать согласие TDLib, ввести собственные API ID / API hash внутри приложения и подтвердить клиентскую авторизацию. Аккаунт TDLib должен совпасть с Telegram Login. Проверить загрузку именно созданных этим аккаунтом ботов, поиск и обновление списка. Время проверки и ошибки источника должны оставаться различимыми.
4. **Бот и чаты.** Открыть реального бота, проверить отдельно доступные каналы и группы, роль самого бота и его права. Неизвестное право должно отображаться как «не установлено». Нажатие карточки или «Открыть консоль бота» не запускает polling и не отправляет сообщение.
5. **Консоль и черновик.** Подключить токен выбранного бота только внутри приложения. Проверить четыре стадии диагностики; затем ввести черновик, переключить вкладки и повернуть телефон. При клавиатуре запуск/остановка доступны; в landscape разделы доступны через меню, язык и тема не перекрываются системной панелью. Текст и получатель сохраняются в текущем процессе. Уход в фон останавливает polling; возврат не запускает его автоматически.
6. **Шаблоны и получатель.** Сохранить собственный шаблон, вставить и изменить текст, проверить предпросмотр. Выбрать избранного получателя; права должны проверяться заново. Для проверки предпросмотра можно отменить отправку. Реальную отправку выполняет владелец только после отдельного подтверждения в приложении; успех одного предпросмотра не доказывает доставку.
7. **Системные действия и обновления.** Проверить открытие `@BotFather`, копирование безопасного JSON и записи события, поиск и фильтры. Проверка обновлений в консоли и профиле использует один Android-источник. Номер сайта не предлагается как версия APK. Несовместимый сертификат не должен запускать установку. Реальные «Позже» / «Что нового» требуют соответствующего опубликованного Android-выпуска; синтетическое окно в CI не является таким выпуском.
8. **Сохранение и выход.** Перезапустить процесс и проверить восстановление зашифрованной аккаунтной сессии. Bot API-токен после уничтожения процесса вводится заново. Выйти явно, проверить закрытие консоли и удаление локальной сессии; после нового запуска старый аккаунт и его инструменты не должны появляться. Не выдавать локальное удаление за подтверждённый удалённый отзыв, если Telegram его не подтвердил.

## Как записать результат без секретов

Указать имя APK/номер CI, установленную версию, выполненные пункты и наблюдаемый результат. Допустимы снимки обычного интерфейса с заранее скрытыми личными данными. Не включать токены, API hash, QR/ссылки авторизации, коды, пароли, сообщения и идентификаторы личных чатов.

На момент подготовки `env -u LD_LIBRARY_PATH -u LD_PRELOAD adb devices -l` выполнен успешно, список пуст. Без авторизованного подключения ADB Termux не может подтвердить экран установщика и runtime другого приложения. Подтверждение владельца либо новое авторизованное ADB-подключение остаётся необходимым для этих пунктов.
